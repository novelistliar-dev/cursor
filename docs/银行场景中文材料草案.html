附录：银行场景中文材料草案（实验一）

供预试验与正式实验使用；可按平台排版分页。方括号为条件差异。

A. 共同设置 + 知识背书

请设想你处于以下情境：

周五下午，你和同事彼得一起下班开车回家。你们打算去银行把工资存进去。开车经过银行时，你们发现里面排队的人很多——周五经常如此。彼得问你：知不知道银行明天（周六）会不会开门。如果明天开门，你们就可以明天再来，那时人会少一些。

你记得三周前的一个周六去过这家银行。据此，你会怎么回应？

  • 「我知道银行明天会开门。」
  • 「我不知道银行明天会不会开门。」

（若选后者，问卷结束并致谢。）

B. 条件续写

B1. 中性（NEUTRAL）

就在这时，你的伴侣打来电话，告诉你孩子生病了，还在医院等挂号；并请你回家后浇浇花、准备晚饭。家里食材够用，不必额外采购。你答应了。挂断电话后，彼得问你：

你还坚持刚才那句「我知道银行明天会开门」吗？

B2. 风险抬升（STAKES）

就在这时，你的伴侣打来电话，告诉你：这笔工资最迟必须在周六存进账户。有一笔非常重要的自动扣款即将到期，账户余额明显不够。你意识到：如果今天直接回家、明天却发现银行关门，会是一场灾难。挂断电话后，彼得问你：

你还坚持刚才那句「我知道银行明天会开门」吗？

B3. 反证证据（EVIDENCE）

就在这时，你的伴侣打来电话，说自己今天早些时候去过你们银行的另一家网点，告示写着该网点已不再周六营业。你朝眼前这家网点望去，也看到一块类似告示，距离太远看不清，但似乎与营业时间有关。挂断电话后，彼得问你：

你还坚持刚才那句「我知道银行明天会开门」吗？

C. 因变量题组（通过背书者作答）

C1. 公开撤回

请选择你更可能给出的回应：坚持 / 不坚持

信心：1（非常没信心）–7（非常有信心）

C2. 私密认识判断

请先不考虑“该不该说出口”。就你自己的判断而言，你现在是否认为自己知道银行明天会开门？

知道 / 不知道 + 信心

C3. 断言适宜性

在当前情形下，再说「我知道银行明天会开门」是否合适？

合适 / 不合适 + 信心

C4. 行动许可

你是否必须先核实银行明天是否开门，才能安心直接回家、改到周六再去？

必须先核实 / 不必核实 + 信心

C5. 取消性四选一

哪一项最符合你的想法？

  • A. 我知道银行明天会开门；但仍必须先核实再按此安排行动。
  • B. 我知道银行明天会开门；不必核实即可按此安排行动。
  • C. 我不知道银行明天是否开门；必须先核实。
  • D. 我不知道银行明天是否开门；也不必核实。

D. 检查题示例

  1. 1. 根据故事，你多久以前在周六去过这家银行？（三周前 / 两周前 / 三个月前 / 故事没说）
  2. 2. 〔STAKES〕这笔钱最迟何时必须存入？（周六前 / 随时都行 / …）
  3. 3. 〔EVIDENCE〕伴侣提到的告示内容大致是？（不再周六营业 / 排队须取号 / …）

E. 第三人称改写要点（实验二）

  • 改为：你问彼得是否知道明天开门；彼得说记得三周前周六来过。你说：「这么说，你知道银行明天会开门。」
  • 续写中向伴侣提及「彼得知道明天开门」；挂断后由伴侣/彼得追问你是否仍坚持该归因。
  • C2 改为：彼得是否仍算知道？C3：现在说「他知道」是否合适？
